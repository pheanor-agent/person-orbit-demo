해석과 한계

첫 제출에서 P1/P4는 세 모델 모두 기능을 통과했습니다. P2의 세 후보와 P3의 두 후보는 여러 애니메이션 클립 때문에 뷰어에서 다리가 멈췄고, 단일 수정으로 전체 동작을 한 클립에 묶었습니다. P3 Opus의 최초 두 번째 단계는 완료 소스가 없어 수정 호출의 결과를 별도로 기록했습니다. 간단한 절차형 ORBIT 어셋에서는 Blender 없이 GLB를 만드는 두 경로가 실용적입니다. 이 시험은 스킨·복잡한 리깅·편집 도구의 대체 가능성을 검증하지 않습니다.

점수는 형태 25, 자전거 20, 접촉 20, 동작 20, 뷰어 사용성 15를 0–5 등급으로 평가한 검토자 한 명의 가중 점수입니다. 실제 화면의 세 주기 재생, 네 위상과 네 방향을 보고, 접촉 거리를 휠 반지름으로 나눈 값 ≤0.03, 4초 단일 클립, 루프 양 끝의 월드 좌표도 독립 계산했습니다. - Exploratory comparison, one reviewer; selected cells n=3, P2/P3 n=1. No statistical claim of general model superiority. - Initial screening model labels hidden until first-pass ratings sealed. Route blinding was partial. Repairs and confirmation are producer-aware/unblinded. - Same frozen ORBIT outdoor auto-background and 1280x900 viewport; not neutral studio background. - Native wrappers, tokenizers and cache accounting differ. Pilot/setup/unused calls and common orchestration usage are separate.

토큰·비용

token-ledger.json은 실제 터미널 사용량 영수증을 호출당 한 번만 계산합니다. 추론 토큰은 출력 토큰에 포함되어 있어 추가로 더하지 않습니다. OpenAI 캐시 토큰은 입력의 부분집합이고 Claude 캐시 읽기·쓰기는 일반 입력에 더했습니다. 미확인 사용량은 0으로 채우지 않았습니다. 금액은 API 정가를 적용한 비교용 추정이며 기존 구독에서 실제 청구된 금액은 미확인입니다. 공통 작업·실패한 준비 작업은 orchestration-usage.json과 비정규 호출 기록에 별도 보존했습니다. 공통 작업의 캐시 입력이 커서 이 실행 전체의 효율과 참가 모델의 제작 효율을 구분해야 합니다.

  • astra 공식 정가
